# 퍼니싱 블랙 록 슈터 모델 참고 가능성

**판정: 3D 형태·의상·재질의 참고 자료로 사용 가능. 원본 4K 애셋이나 PSP에 그대로 넣는 교체 모델은 아님.**

## 실제 파일 확인

- 설치 위치: `Y:\Punishing Gray Raven Game`. 실행 런처 기록에서 추적했다. D:는 런처 위치였다.
- 조사 시 package_version `2.7.1`, Unity 번들 버전 `2018.4.30f1`.
- 리소스 색인 23,866항목. 이름 검색 후보에는 별도 BlackrockChess 콘텐츠도 섞이므로 모두 BRS 이벤트라고 계산하지 않는다.
- BRS 몸체 2종·메시·프리팹·무기·이벤트 UI의 8개 번들을 선택해 텍스처 66개, 메시 16개를 추출했다.
- 선택한 파일은 색인의 SHA-1 및 크기와 일치한다. 추출 전후 SHA-256도 같았다. 업데이트 중인 게임 원본은 수정하지 않았다.

이 수치는 선택한 로컬 번들에 대한 것이다. 게임 전체에 4K 이미지가 없다는 뜻은 아니다. 4K는 텍스처 또는 출력 화면 해상도에 관한 말이며 메시 자체의 등급이 아니다.

## 사용법 및 검증

`BRS_model_reference.html`을 열면 기본/추가 의상 선택, 드래그 회전, 휠 확대, 와이어프레임 확인이 가능하다. 인터넷 연결 없이 열린다.

GLB 2개는 Blender 등에서 여는 **정적 참고 모델**이다. 몸체 6개 메시만 합쳐 별도 검은 제외했다. 기본 모델은 18,863삼각형, 추가 의상은 23,704삼각형이다. 원본 컬러 텍스처와 UV를 연결했으며 툰 셰이더·조명·본·표정·애니메이션을 GLB에 이식하지 않았다. 게임 화면과 광택·윤곽·눈 표현이 다를 수 있다.

두 의상의 메시 조립과 텍스처 정렬을 실제 브라우저에서 확인했다. GLB 길이·삼각형 인덱스·UV/법선 정점 수 검사를 통과했다. 추출 오류는 0개다.

## PSP 리텍스처 활용 판단

- 머리카락 흐름, 코트 봉제선·지퍼·별 문양, 무기 형태·재질의 참고로 유용하다.
- PSP판 스텔라의 의상·실루엣 및 기존 UV 위치에 맞춘 고해상도 텍스처를 별도로 제작해야 한다. 퍼니싱판 디자인을 그대로 옮기면 PSP 원작과 달라질 수 있다.
- PPSSPP 텍스처 교체는 이미지 교체 기능이다. GLB를 넣어 메시·뼈대를 교체할 수 없다. 모델 이식은 게임 내부 형식·본·애니메이션 변환을 별도로 검증하는 작업이다.
- 한국어 메뉴는 기존 문구·좌표·알파·상태를 보존해 재조판해야 한다. 퍼니싱 캐릭터 모델은 메뉴 글자의 선명도를 높이는 직접 재료가 아니다.

이번 결과는 **참고 자료 평가와 정적 미리보기**까지다. PSP에 적용한 리텍스처 팩이나 한국어 메뉴 4K 완료본은 아니다. 기존 메뉴 27장의 현재 판본 해시·UV·화면 검증과 새 제작이 남아 있다.
