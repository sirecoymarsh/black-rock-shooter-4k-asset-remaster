
# BLACK★ROCK SHOOTER THE GAME — 4K 애셋 리마스터

`NPUH10126`용 PPSSPP 고해상도 텍스처 교체 팩을 제작하는 독립 작업 공간입니다.

## 목표

- 한국어 패치판에서 실제로 호출되는 텍스처 해시를 기준으로 전 화면을 조사합니다.
- UI만이 아니라 캐릭터, 적, 배경, 전투 HUD, 효과, 컷신 관련 텍스처까지 분류합니다.
- 원본 비율·알파·UV·상태 변형을 보존하면서 4배 또는 8배 해상도 후보를 제작합니다.
- `textures.ini`와 PNG 결과물을 재현 가능한 매니페스트로 관리합니다.
- PPSSPP 적용 전후 화면을 동일 장면에서 비교하여 런타임 검증합니다.

## 원칙

- 텍스처팩은 PPSSPP의 `ReplaceTextures=True` 기능을 사용합니다. 모델 이식은 원본 ISO를 보존하고 별도 시험 ISO에만 적용합니다.
- 실제 덤프 해시 없이 파일명을 추정하지 않습니다.
- 원본 게임 ISO와 무가공 덤프는 Git에 커밋하지 않습니다.
- 기존 한국어 패치용 HD UI 27장은 기준 자료이며 전체 리텍스처의 완료를 의미하지 않습니다.

진행 상황은 `PROGRESS.md`, 기존 작업 위치는 `references/KNOWN_PATHS.md`를 확인합니다.

## 추가·변경 사항

이 절은 이 저장소가 원판(미국 PSN판 `NPUH10126`)과 기존 한국어 패치 v1.0.1에 **무엇을 더하려 했고, 어디까지 만들었는지**를 커밋 기록·`PROGRESS.md`·체크포인트 문서에서 모아 정리한 것입니다. 괄호 안은 근거(커밋 앞 7자, 파일 이름)이며, 확실하지 않은 내용은 「(추정)」으로 표시했습니다.

### 한국어 패치 저장소와의 관계

- **[BRS-Korean-NPUH10126](https://github.com/sirecoymarsh/BRS-Korean-NPUH10126)이 한국어 패치 본체**입니다. 그쪽은 원본 ISO에 차분을 적용해 한국어판 ISO(v1.0.1, SHA-256 `525b5d2b…3728fc92a`)를 만들고, 선택 설치로 8배 HD UI 27장을 줍니다. 공개 배포가 끝난 완성품입니다.
- **이 저장소는 그 한국어 패치 v1.0.1 적용본을 기준으로 한 별도의 고화질화 작업**입니다. 한국어판에서 실제로 불리는 텍스처를 모아 UI뿐 아니라 캐릭터·적·배경·전투 HUD·효과까지 PPSSPP 고해상도 텍스처 팩으로 만들고, 퍼니싱: 그레이 레이븐(PGR)의 블랙★록 슈터 얼굴·의상 모델을 PSP 모델로 옮겨 보는 것이 목표였습니다(`PROJECT.md`).
- 한국어 패치의 HD UI 27장은 이 작업의 **기준 자료**이며, 이 저장소가 그 27장을 새로 만든 것은 아닙니다.
- **상태: 중단(일시정지) 체크포인트.** 2026-09-23에 사용자 요청으로 애셋 제작을 멈추고 Git에 체크포인트로 저장했습니다(27e9e7d, `asset-remaster/RESUME.md`). 그 뒤 성공 버전 보존(2026-09-24)과 아이콘·한국어 UI 체크포인트(2026-09-29)를 더 남겼습니다. **배포용 팩이나 릴리스는 없습니다.**

### 화면·그래픽 개선 (만든 후보)

- **전투·필드 텍스처**: 확인된 전투·고유 필드 텍스처 635종 가운데 354종(55.75%)이 정적 검수를 통과한 후보이고, 420종(66.14%)은 한 번 이상 처리했습니다. 필드만 보면 후보 113, 보류 49, 미처리 189입니다. 이 수치는 **게임 전체 완료율이 아닙니다**(`asset-remaster/records/qa/paused_checkpoint_20260923.json`). 마지막으로 확정된 묶음은 FIELD-FOLIAGE-007이고, FIELD-FOLIAGE-008의 식물 보정 4종은 미검수로 따로 두었습니다.
- **해상도**: 원본의 4배 또는 8배(작은 UI는 8배)로 만들며, 「4K」는 프로젝트 이름일 뿐 모든 PNG가 4096픽셀이라는 뜻은 아닙니다.
- **글꼴 선명화(FONT-RUNTIME-001)**: 게임 글꼴의 한글 919자 + 영문·숫자·기호 92자를 Orbit 벡터 글꼴로 다시 그려 671개 정확 매핑으로 넣었습니다. 리페어 200/500/800/1000, 스킬 이름 등 흐리던 글자가 선명하게 보이는 것을 실게임에서 확인했습니다. 아직 관측하지 않은 글자 배열은 원본(저해상도)으로 나올 수 있습니다(bcb6d72, `PROGRESS.md` 2026-09-24).
- **스텔라(부스터 유닛) 몸체 질감**: 256×256 원본을 2048×2048(8배)로 보정한 후보를 만들어, 부스터 유닛 메뉴 화면에서 실제 GPU에 올라가는 것을 픽셀 단위로 확인했습니다. 노멀 슈트(기본 의상)용 후보는 아직 없습니다(`PROGRESS.md` 2026-09-22).
- **아이콘**: 공통 버튼·무기·상태·훈장·조준·필드·미니맵·갤러리 표식 61묶음(원본 같은 모양 95개)을 원본 모양·색·굵기에 맞춰 8배로 보정했습니다. 한국어 UI와 합쳐 243키/81PNG의 UI 델타입니다(4ddc988).
- **얼굴·의상 모델 이식**: PGR 얼굴·눈·머리·몸·코트·지퍼(15,846정점, 18,863삼각형)를 PSP 47관절에 맞춰 변환한 부스터 유닛 교체 모델 후보를 만들었습니다. 표정 블렌드셰이프는 옮기지 않았고, 손가락·보조 관절은 단순화했습니다(a9625e6, `model-port/README.md`).

### 버그 수정 (작업 중 해결한 것)

- **부스터 유닛 PGR 모델 로딩 멈춤**: 모델 힙 1.5MiB에서 3.6MB 압축 해제 버퍼를 못 잡아 멈추던 문제를, 모델 힙 6MiB 등 메모리 배치 네 곳을 고쳐 해결했습니다. PARAM.SFO의 MEMSIZE=1과 64MiB(PSP Slim) 설정이 필요합니다. 모델 전체가 RAM 두 곳에서 정확히 일치하고 사용자가 동작을 확인했습니다(bcb6d72, `checkpoints/booster-working-20260924/README.md`).
- **수집 세션 소리 문제**: 숨김 수집 세션에서 소리가 나던 설정 오류를 고쳤습니다(`PROGRESS.md` 2026-09-22).

### 설치·제거 방식

- 정식 설치 방식은 아직 없습니다(배포 ZIP 미완성). 목표는 ISO와 분리된 선택 설치형 PPSSPP 텍스처 팩(`textures.ini` + PNG, `ReplaceTextures=True`)입니다.
- 모델 이식과 타이틀 한글화는 텍스처 팩만으로 안 되고 별도 시험 ISO가 필요합니다. 원본 ISO는 보존하고, 입력·출력 ISO를 SHA-256으로 확인합니다(성공 통합본 ISO `b162f45f…43de9b21`, 타이틀 v2 ISO `a923932d…876e1572`).
- `apply_checkpoint.py`는 적용 전 ISO·INI·매니페스트를 `ui-backups`에 백업하고 해당 243키만 병합합니다. 되돌릴 때는 백업 폴더의 파일을 다시 복사합니다.
- 원본 ISO·무가공 추출물·모델 가중치·에뮬레이터·세이브는 Git에 넣지 않았고 작업 PC에만 있습니다. `historical-tools/`와 `tools/`의 일부 스크립트는 작업 PC의 경로를 전제로 하므로 다른 컴퓨터에서 그대로 실행하면 안 됩니다.

### 알려진 문제

- **중단 상태**입니다. 사용자가 다시 시작하라고 할 때까지 새 애셋 제작을 하지 않기로 기록돼 있습니다.
- 아이콘·한국어 UI 체크포인트(2026-09-29)는 통합본에 설치만 했고 실게임 화면 확인은 하지 않았습니다. 아이콘 연결 225키 가운데 실제 관측은 38키뿐이고 187키는 계산한 후보입니다.
- 부스터 유닛 모델은 메뉴 로딩까지만 확인했고, 이동·전투·의상 반복 변경·장시간 플레이는 검증하지 않았습니다. 직접 화면 캡처도 없습니다.
- 2026-09-22 의상 변경 후 이동 중 검은 화면이 한 번 보고됐고 원인은 확정되지 않았습니다.
- 글꼴 선명화는 관측한 배열만 바꾸므로, 처음 보는 화면의 글자는 흐릴 수 있습니다.
- 게임 전체 텍스처의 총수를 아직 모릅니다. 지역 1~6, EX/진엔딩, 컷신 수집이 남아 있습니다.
